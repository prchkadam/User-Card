# User Card ID
A modern and responsive **User Card UI Project** built using **React.js**.
This project focuses on creating clean and aesthetic user profile/job cards with modern layouts and responsive design principles.

---

## 🚀 Live Demo
```txt
https://useridcard.vercel.app/
```

---

# 📌 About The Project
This is one of my first projects built while learning **React.js** and modern frontend development.

The goal of this project was to:
* understand React component structure
* practice reusable UI components
* improve CSS layout skills
* learn responsive grid systems
* experiment with modern UI aesthetics

The project displays multiple responsive cards in a clean modern layout inspired by contemporary UI/UX designs.

# ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/prchkadam/User-Card.git
```

Navigate into the project folder:

```bash
cd User-Card-ID-
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
